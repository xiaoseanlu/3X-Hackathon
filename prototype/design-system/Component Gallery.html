Rules
• View stack: JS array, push on navigate, pop on back
• ExpertFooterCard hides in expert and chat views
• Back button appears in header when stack depth > 1
• All views are absolutely positioned inside a relative container

• Every layer-2 detail view ends with the Susan CTA block
